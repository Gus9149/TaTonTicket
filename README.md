# TaTonTicket — site vitrine

Site statique (HTML/CSS, sans dépendance) présentant l'application Android TaTonTicket, le carnet de dépôts numérique de l'artisan. Prévu pour GitHub Pages.

- `index.html` : accueil, fonctions, sécurité, tarifs, FAQ, contact
- `mentions-legales.html`, `confidentialite.html` : **modèles à compléter** avant le lancement
- `assets/` : icône de l'app

## À faire avant le lancement

- Remplir les champs « à compléter » des pages légales.
- Remplacer les emplacements « Capture à venir » par de vraies captures d'écran.
- Remplacer « Bientôt disponible » par le lien Google Play.
